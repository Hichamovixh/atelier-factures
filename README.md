# Atelier Factures

Générateur de factures et de devis personnalisés, en une seule page HTML.

- Facture ou devis, transformation devis → facture
- Logo, couleur, devise, coordonnées (SIRET, TVA, IBAN)
- TVA personnalisable par ligne, nom de taxe modifiable, exonération art. 293 B du CGI
- Remise, acompte, mentions légales
- Signature dessinée ou importée
- Export PDF

Aucune installation : ouvrez `index.html` dans un navigateur, ou publiez-le avec GitHub Pages.
Les données restent dans le navigateur (localStorage), rien n'est envoyé à un serveur.
